# VPN Admin Console

Внутренняя административная панель на Next.js, Refine и shadcn/ui.

Перед работой прочитайте документы соседнего backend-репозитория:

- `docs/PROJECT_OVERVIEW.md`
- `docs/ROADMAP.md`
- `docs/REPOSITORY_MAP.md`
- `docs/HANDOFFS/ADMIN_CONSOLE.md`

Admin Console использует только admin API и не обращается к БД или VPN-панелям напрямую.
