# Как работают UTM-метки на платформе

Эта инструкция — как размечать ссылки на посадочные страницы брендов, чтобы платформа сама посчитала, откуда пришёл клиент и сколько денег он принёс.

## Как собрать ссылку

Добавьте к обычной ссылке на сайт бренда параметры `utm_*` через `?` (первый параметр) или `&` (последующие):

```
https://demon-vpn.ru/?utm_source=vk&utm_medium=cpc&utm_campaign=avgust_2026
```

Поддерживаются пять стандартных параметров:

| Параметр | Что означает | Пример |
|---|---|---|
| `utm_source` | **Обязательный.** Источник трафика — без него метка не сработает вообще | `vk`, `telegram`, `yandex_direct` |
| `utm_medium` | Канал/формат | `cpc`, `post`, `email`, `referral` |
| `utm_campaign` | Название конкретной кампании | `avgust_2026`, `black_friday` |
| `utm_content` | Различение вариантов объявления/креатива внутри кампании | `banner_a`, `banner_b` |
| `utm_term` | Ключевое слово (для контекстной рекламы) | `купить vpn` |

`utm_source` — единственный обязательный параметр. Если его нет в ссылке — метка не запишется вообще, даже если остальные `utm_*` присутствуют.

## Как это работает технически (коротко)

1. Человек переходит по ссылке с `utm_*`-параметрами на сайт бренда.
2. Сайт один раз сохраняет метку в cookie (на 30 дней) — если у посетителя уже есть сохранённая метка, новая не перезаписывает её (учитывается только **первое** касание).
3. Если человек потом регистрируется (проходит email-OTP), метка из cookie прикрепляется к его аккаунту в этом бренде — один раз, навсегда. Повторные заходы/покупки эту привязку не меняют.
4. В админке, в разделе **Каналы привлечения**, видно по каждой комбинации `utm_source`/`utm_medium`/`utm_campaign`: сколько регистраций, сколько из них стали платящими, и сколько денег каждый канал принёс (по первой оплате — продления это число не раздувают).

## Важные ограничения

- **Метка живёт 30 дней.** Если человек перешёл по ссылке, но зарегистрировался только через 2 месяца — привязка не сработает, регистрация уйдёт в «органические» (без метки).
- **Первое касание побеждает.** Если человек сначала пришёл с одной рекламы, а через неделю — с другой, засчитается первая ссылка, по которой он вообще попал на сайт.
- **Регистр и написание важны.** `utm_source=VK` и `utm_source=vk` — для системы это два разных источника. Договоритесь заранее об одном написании для одного канала и используйте его везде.
- Ссылки без `utm_source` (обычный переход на сайт, поисковик, прямой ввод адреса) считаются **органическими** — это отдельная строка в статистике, не ошибка и не «потерянные» данные.

## Где посмотреть результат

Админка → **Каналы привлечения** — таблица по всем меткам: регистрации, конверсия в оплату, выручка по каждой.
