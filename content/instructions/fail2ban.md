# fail2ban для VPS с админкой

## Установка (Ubuntu/Debian)

    sudo apt update && sudo apt install -y fail2ban

## Базовая конфигурация

Создать `/etc/fail2ban/jail.local` (не трогать `jail.conf` напрямую — апдейты пакета его перезапишут):

    [DEFAULT]
    bantime = 1h
    findtime = 10m
    maxretry = 5
    backend = systemd

    [sshd]
    enabled = true
    port = ssh

## Приоритет

Админка будет доступна только через WireGuard (не публично) — поэтому защита SSH это приоритет №1, единственный публично видимый сервис на сервере. Даже если SSH дополнительно ограничен на firewall только WG-подсетью, fail2ban стоит держать как второй независимый слой защиты — на случай ошибки в правилах firewall.

## Полезные команды

Проверить статус:

    sudo fail2ban-client status sshd

Разбанить IP (если случайно забанили себя):

    sudo fail2ban-client set sshd unbanip <IP>

## На будущее

Если у самой админ-панели есть лог неудачных попыток входа сотрудников, можно завести отдельный fail2ban jail, который парсит этот лог и банит IP после N неудачных попыток. Потребуется написать свой `filter` (regex под формат наших логов) — из коробки fail2ban про это не знает. Отдельная небольшая задача, не обязательна сразу.
